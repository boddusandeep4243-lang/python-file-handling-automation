# Python File Handling & Automation

## Project Description

This project demonstrates Python file handling and basic file automation.

The project performs operations such as:

* Reading and writing TXT files
* Reading and writing CSV files
* Renaming files
* Moving files
* Deleting files
* Handling errors using `try-except`

## Technologies Used

* Python
* TXT File Handling
* CSV File Handling

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code or another Python editor.
4. Run:

```bash
python file_handling.py
```

## Error Handling

The project uses `try-except` blocks to handle common file-related errors, such as missing files or invalid operations.
